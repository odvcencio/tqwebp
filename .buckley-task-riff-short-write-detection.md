## Deterministic defect

`WriteSimpleLossy` checks only the error returned by each `io.Writer.Write` call. If a writer returns fewer bytes than requested with a nil error, the function continues and ultimately returns nil. The public encoder can therefore report success after writing a truncated RIFF header, VP8 payload, or odd-byte padding.

The exact baseline probe uses a writer whose `Write` returns `len(p)-1, nil` and calls:

```go
err := WriteSimpleLossy(shortWriter{}, []byte{0x9d, 0x01, 0x2a})
```

Exact main fails deterministically with:

```text
WriteSimpleLossy error = <nil>, want io.ErrShortWrite
```

This is not speculative. Canopy traces:

```text
webp.Encode
  -> internal/encoder.Encode
  -> (*encoder).writeFile
  -> container.WriteSimpleLossy
```

`(*encoder).writeFile` returns `WriteSimpleLossy`'s result unchanged, so this is the public codec's success/error boundary. No open PR touches `internal/container`.

## Required behavior

Implement the smallest coherent correction and tests proving:

1. A short nil-error write of the 20-byte RIFF/WEBP/VP8 header returns an error matching `io.ErrShortWrite` and stops immediately.
2. A short nil-error write of the VP8 payload returns an error matching `io.ErrShortWrite` and stops before any padding write.
3. For an odd-size payload, a short nil-error write of the one-byte pad returns an error matching `io.ErrShortWrite`.
4. A non-nil underlying writer error is propagated rather than replaced.
5. Successful even- and odd-size writes still emit the exact existing RIFF layout and `Size(payloadLen)` still equals the written byte count.

Follow normal Go `io.Writer` semantics: inspect both `n` and `err` for each requested slice. Do not silently retry a contract-violating nil-error short write, because callers need an explicit failure and retries can duplicate bytes for stateful writers. Avoid allocation beyond the existing header and one-byte pad.

## Exact production source

Current `internal/container/container.go`:

```go
// Package container writes the RIFF wrapper of a simple lossy WebP file,
// as the WebP container specification defines it.
//
// The layout is short:
//
//     "RIFF" u32(fileSize) "WEBP" "VP8 " u32(payloadSize) payload [pad]
//
// The RIFF size field counts every byte after itself. A chunk of odd size
// takes one zero pad byte, and the pad byte counts towards the RIFF size.
// Alpha needs the extended layout with a VP8X chunk and an ALPH chunk,
// which work package WP-5 adds.
package container

import (
    "encoding/binary"
    "fmt"
    "io"
)

// MaxPayload is the largest VP8 payload the container can carry. The RIFF
// size field holds 32 bits, and the header before the payload takes 12 of
// them.
const MaxPayload = 1<<32 - 1 - 12

// WriteSimpleLossy writes payload, a VP8 key frame, to w inside a RIFF
// WebP container.
func WriteSimpleLossy(w io.Writer, payload []byte) error {
    if len(payload) > MaxPayload {
        return fmt.Errorf("tqwebp: VP8 payload of %d bytes does not fit a RIFF container", len(payload))
    }
    pad := len(payload) & 1
    var header [20]byte
    copy(header[0:4], "RIFF")
    binary.LittleEndian.PutUint32(header[4:8], uint32(4+8+len(payload)+pad))
    copy(header[8:12], "WEBP")
    copy(header[12:16], "VP8 ")
    binary.LittleEndian.PutUint32(header[16:20], uint32(len(payload)))

    if _, err := w.Write(header[:]); err != nil {
        return err
    }
    if _, err := w.Write(payload); err != nil {
        return err
    }
    if pad == 1 {
        if _, err := w.Write([]byte{0}); err != nil {
            return err
        }
    }
    return nil
}

// Size returns the exact number of bytes WriteSimpleLossy writes for a
// payload of the given length.
func Size(payloadLen int) int {
    return 12 + 8 + payloadLen + payloadLen&1
}
```

## RIFF byte-layout oracle for focused tests

For payload `[]byte{0x01, 0x02, 0x03}`, the exact valid output is 24 bytes:

```text
52 49 46 46 10 00 00 00 57 45 42 50 56 50 38 20
03 00 00 00 01 02 03 00
```

Explanation:

- `RIFF`
- little-endian RIFF size 16 (all bytes after the size field)
- `WEBP`
- `VP8 `
- little-endian payload size 3
- three payload bytes
- one zero pad byte

For even payload `[]byte{0x01, 0x02}`, the output is 22 bytes, the RIFF size is 14, and there is no pad byte.

A focused selective writer can count calls, fully accept all calls before a chosen failure call, then either return `len(p)-1, nil` or a sentinel error on that call. Assertions should confirm the returned error and that no subsequent write occurred. Keep test helpers private to the test file.
