## Speed and memory

Across all inputs at q75, median time relative to cwebp is 0.61x for method 4,
1.87x for method 5, and 7.76x for method 6. The CGo ratios are 1.13x for chai
and 0.85x for bep. cwebp includes command overhead; Go timings do not.

Median Go allocation volume per megapixel is 6.82 MiB for method 4,
6.55 MiB for method 5, and 171.99 MiB for method 6. These are allocation
volumes, not peak live memory. The output buffer is warm.

The separate RSS capture includes each process, source decode, warmup, and
one timed Go encode plus an allocation probe. cwebp has one CLI encode.
On the 1200 by 800 package screenshot, peak RSS was 17.46 MiB for method 4,
17.48 MiB for method 5, 33.83 MiB for method 6, 24.41 MiB for chai,
20.61 MiB for bep, 62.42 MiB for nativewebp, and 11.71 MiB for cwebp.
See `memory-2026-09-23.json`. These are whole-process measurements.
